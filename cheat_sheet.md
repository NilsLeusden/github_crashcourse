## level 1.

**git config --global user.name "Je naam"**				zet hier je voor en eventueel achternaam.
**git config --global user.email "you@example.com"**	zet hier je email (liefst dezelfde als github)	
**git clone <link>**									download de repository voor de eerste keer
**

## Level 2.

**git status**					wat is de status van de repository.
**git add .**					voeg alle bestanden toe
**git add voorbeeld**			voeg 1 bestand toe
**git commit -m "message"**		maak een checkpoint aan, plus omschrijving tussen de " "
**git push / git pull**			upload naar cloud / download nieuwste versie van cloud
**git switch -c name**			maak een nieuwe tak aan.
**git switch name**				verander naar een tak toe.
**git log --oneline**			kijk naar het logboek van commits, waar ook de beschrijvingen in staan.

## Level 3.

**git merge (naam branch)**		merged de genoemde branch naar huidige
**git rebase**					n.v.t.
